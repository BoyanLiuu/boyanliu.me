Dark Room is a movie discovery website built on [The Movie Database (TMDB) API](https://www.themoviedb.org/documentation/api). Everything you see, from posters and ratings to cast lists and trailers, is requested live from TMDB in the browser.

## What it does

- **Browse the catalog:** carousels for _Now Playing_, _Trending_, _Upcoming_ and _Top Rated_ movies on the home page, plus a browse page for paging through popular titles.
- **Search:** find any movie by title.
- **Movie pages:** overview and details, the cast, user reviews and the official trailer, embedded from YouTube.
- **Cast pages:** an actor's profile and filmography, so you can hop from one film to the next.

## How it's built

| Layer      | Choice                                                |
| ---------- | ----------------------------------------------------- |
| Markup     | Five HTML pages: home, browse, search, movie and cast |
| Styling    | Custom CSS on Bootstrap 4, Font Awesome, Animate.css  |
| Behaviour  | JavaScript and jQuery 3.3, with AJAX calls to TMDB v3 |
| UI plugins | Slick carousel, Smooth Scroll, Sticky-kit             |
| Hosting    | GitHub Pages (static files, no build step)            |

A small `config.js` holds the API base URLs and key; `main.js` contains the page logic: fetching each catalog list, the movie details, credits, reviews and trailer for a title, and an actor's movie credits, then building the cards and carousels with jQuery.

## What I'd do differently

- Keep the API key out of the browser by calling TMDB through a small serverless proxy.
- Rebuild the pages as components (for example in React) instead of assembling HTML strings with jQuery.
- Lazy-load posters and cache API responses to make browsing faster on slow connections.
